UI/UX designer.

Design a complete web application mockup for a university research management system called LPPM x SISTER.

The goal of the platform is to manage lecturer research submissions, review processes, and publications.

Focus only on UI/UX mockups and layout, not backend or coding.

Design clean, modern, and professional dashboards suitable for an academic institution.

SYSTEM ROLES

The system supports four roles:

Public (Umum)

Lecturer (Dosen)

Reviewer

Admin

Each role should have different interface views.
